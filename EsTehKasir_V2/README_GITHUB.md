# Es Teh Kasir v2.0 — Build APK Online

Upload the contents of this project to your GitHub repository.

Then:
1. Open the repository's **Actions** tab.
2. Choose **Build Es Teh Kasir APK**.
3. Click **Run workflow**.
4. Wait for the green check mark.
5. Open the completed workflow run.
6. Under **Artifacts**, download **EsTehKasir-v2.0-debug-apk**.
7. Extract the downloaded artifact and install `app-debug.apk` on Android.
