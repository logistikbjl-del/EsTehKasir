# Es Teh Kasir v2.0

Project Android offline untuk satu toko.

Fitur:
- Kasir dan keranjang
- 5 menu awal: Es Teh Jumbo, Es Jeruk, Matcha, Thai Tea, Green Tea
- Tambah/edit/hapus produk dari HP
- Kategori, harga, stok, aktif/nonaktif
- Stok berkurang saat transaksi
- Riwayat ringkas melalui jumlah transaksi
- Laporan omzet tersimpan lokal
- Tidak membutuhkan internet

Harga awal:
Es Teh Jumbo Rp8.000
Es Jeruk Rp7.000
Matcha Rp12.000
Thai Tea Rp10.000
Green Tea Rp10.000

Buka folder di Android Studio, Sync Gradle, lalu Build APK.
